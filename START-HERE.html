Price update, 4 simple steps.

  1. Editor kholein: Open price editor par click karein. Products & prices tab mein rate aur unit likhein.
  2. File save karein: Download updated file dabayein. Download nazar na aaye to Save site-data.js use karein. Copy/save alternative bhi wahin hai.
  3. Purani file replace karein: nayi file ka exact naam site-data.js rakhein aur website folder mein existing file ki jagah rakh dein. Backup rakhna behtar hai.
  4. Check aur upload: website refresh karke price dekhein. Live site ko update karne ke liye updated website folder dobara upload karein.

Blank price = “Ask for a quote”. Zero = “Rs 0”. Editor aapki live website ko automatically change nahi karta.
